# sohumvajaria.github.io

Personal site. Next.js (static export) + Tailwind + shadcn/ui, with animated components from Magic UI (as listed on 21st.dev).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in ./out
```

Deploys to GitHub Pages from `main` via `.github/workflows/deploy.yml`.
In the repo settings, set Pages > Build and deployment > Source to "GitHub Actions".
